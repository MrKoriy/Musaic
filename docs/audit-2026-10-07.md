# Audit improvements — implementation notes

## Implemented

- Local FTS search uses the table name and treats ordinary punctuation as text.
- Append-only migrations v27–v29: playlist revisions, retention-independent listening rollups and durable playback delivery receipts.
- Stable playlist insertion/append order, revision-aware keyset pagination and versioned cover URLs.
- Client loads visible playlists in 100-track pages. Play, shuffle, download and export use the full playlist.
- Explicit IANA timezone for statistics, UTC minute rollups and per-track lifetime totals; retention cannot reduce totals.
- New search clients use retry-stable cursors with buffered provider results and source alternatives. Suggestions are separate requests; external searches have a six-second response budget.
- Download metadata and JPEG artwork survive relaunches. Downloads are independent of likes, with cancellation, playlist snapshots, AAC 128/192/256 and Wi-Fi-only preferences.
- Persist-before-send playback outbox: stable event IDs, occurrence timestamps, account/server scoping and reconnect retries.
- Metadata JSON/M3U export. M3U uses app-owned `musaic://track/...` references, not credentials, signed provider URLs or private filesystem paths. These references are for Musaic, not generic audio players.
- Siri/App Shortcuts for My Vibe; factual recommendation signals derived from actual ranker features.
- Scaled app typography, 44-point action targets, Reduce Motion-safe bounce, opaque accessibility surfaces, simpler Home/player hierarchy and scrollable accessibility-size player layouts.
- Asynchronous directory I/O, unchanged-file skipping by size/mtime and preservation of loudness fields during legacy source-constraint rebuilds.
- CI preserves build/test commands and emits readable compiler-error annotations.

## Verification

Local server typecheck, lint, tests and bundle build are required before push. Apple builds and Swift tests are verified in PR CI; Linux checks do not replace them.

## Explicit limits

- The 0.25-second crossfade bridge is labelled **Seamless bridge**, not true gapless. Sample-accurate gapless across codecs/providers requires a dedicated audio-engine change and Apple-device playback validation.
- Scan remains in the server process. Process isolation with durable progress/restart recovery is separate work; this branch removes synchronous traversal and redundant metadata parsing.
- The legacy offset search endpoint remains for old clients. New cursor buffers expire after five minutes and require a fresh search after server restart/expiry.
- Rollup migration backfills history still in SQLite. Previously removed JSONL archives are not automatically imported.
- Device QA remains necessary for Dynamic Type, VoiceOver, gestures, OS-terminated downloads, audio interruptions, GPU/battery use and end-to-end latency. No unmeasured percentage speedup is claimed.
- Watch/widget-specific typography is unchanged; app typography changes do not alter extension target dependencies.
